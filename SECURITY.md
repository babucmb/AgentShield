# Security policy

AgentShield is a hackathon prototype. Do not use it for real-money payments or production customer data without a security review.

Report security issues privately to the repository owner. Never publish credentials, PayPal secrets, OpenAI keys, access tokens, personal buyer credentials, or database files in an issue or pull request.

Before production, add HTTPS, secret rotation, rate limiting, encrypted storage, dependency scanning, formal penetration testing, webhook monitoring, and a documented incident-response process.
